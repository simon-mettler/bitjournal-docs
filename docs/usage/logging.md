# Events

You log events from the **Log** screen. An event is built up in a draft bar at the bottom of the screen, and only saved once you press **Save event**.

## Logging an event

Tap a signal card to add it to the draft:

- **Tally**: added immediately.
- **Range**: pick a value on the slider and press **Add**.
- **Value**: enter the value on the number pad and press **Add**.
- **Duration**: enter hours, minutes and seconds, then press **Add**.

Each added signal appears as a chip in the draft bar. Add as many signals as you like, they are saved together as one event.

- Tap a chip to change its value (not available for tallies), or use its ✕ to remove it.
- Set the **date** and **time**. By default it is when you started the draft, so you can also log things that happened earlier.
- **Cancel** discards the draft. **Save Entry** saves it and needs at least one signal.

## Editing an existing event

Open the event's menu in the [Journal](./journal.md) and choose **Edit event**. The Log screen opens with the event loaded. Change what you need and save. Saving replaces the previous version of the event.
