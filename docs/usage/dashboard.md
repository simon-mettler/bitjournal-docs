# Dashboard

The **Dashboard** is made of widgets that you arrange yourself.

Press the pencil icon to edit. In edit mode you can add, reorder, edit and remove widgets.

## Widgets

Use the **Add widget** tile in edit mode to add one, and **Edit widget** on a widget's menu to change it. There are two types:

- [Value widget](./widgets/value-widget.mdx): a single number.
- [Timeseries widget](./widgets/timeseries-widget.mdx): a bar or line chart.

:::info
**More widgets are coming soon!**
They will make analysing your data far more interesting and functional.
:::

Curious how the numbers are calculated? See [Statistics in detail](./statistics.md).
